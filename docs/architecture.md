新增行为应放入职责对应的模块，并添加针对行为与边界情况的单元测试。纯数学和图算法不依赖 React、DOM 或 AudioContext；音频只接收编译后的数值与时序。入口文件和纯转导出文件无需重复测试。

UI 使用 jsdom 和 React Testing Library；音频测试使用可控制的 AudioContext 替身，检查实际提交的频率、增益、起止时间、振荡器复用、取消及资源释放。真实设备上的听感仍需要实际试听。

## 图与编辑规则

- 双击空白添加；单击选中；拖动移动；Del 删除结点及关联边。
- 拖动空白处平移视图；“显示全部”将全部结点连同标签留白纳入视野，必要时缩小显示；“重置视图”返回初始区域。小屏幕画布随容器宽度适配。
- 结点坐标不再限制在初始 1200×800 区域内。创建和拖动通过视图的偏移、比例换算到世界坐标。平移不会修改结点位置、连线长度或音频时长，拖动空白也不会取消已有选择。
- 播放期间允许平移、显示全部和重置视图，结点与连接编辑仍锁定。视图状态仅用于当前界面，不写入作品文件。
- 按住 Ctrl 依次点击 A、B、C，依次创建 A→B、B→C；释放 Ctrl、点击空白或窗口失焦结束连接链。
- 双击连接删除该边，事件不传播成创建结点。
- 单击连接选中并显示连接检查器，可选择 `y = x`、`y = floor(x)` 或 `y = smoothstep(x, 0.95, 1)`。选中连接时 Del 也可删除连接；下拉框内的 Del 不删除。选择结点或空白会退出连接检查器。
- 同向重复边和自连接不创建；反向边合法且错开绘制。
- 所有图按**弱连通分量**划分，即划分时忽略箭头方向。播放时严格沿箭头方向。
- 孤立结点是草稿，不参与播放校验。
- 第一次连边自动以源结点为起点；可选中有出边的结点重新指定。
- 合并两图优先保留源图起点，没有源图起点时保留目标图起点；两者都没有则使用新连接源结点。
- 拆分图或删除起点不会悄悄选择其他起点。每个仍有连接的分量必须具有一个有出边的起点，否则播放报错。
- 同一图所有结点必须具有非空且等长的声音数组，相同 index 的波形一致；包括从起点不可达的结点。不同图之间没有数量或波形兼容要求。
- 不可达结点及其出边淡化显示。不可达分支不会自动回溯播放。
- 输入框内的空格和 Del 不触发全局快捷键；按住空格不重复切换模式。

## 播放语义

1. 全部图通过验证后，才启动所有图。频率必须处于当前 AudioContext 采样率的一半以下；每个声音增益为 0–0.2。
2. 所有图使用同一音频时钟同时出发，各有一个游标及独立的遍历状态。
3. 全局速度单位为画布单位/秒，范围 `(0, 1000]`。连接时长为两端**结点中心的几何距离 / 速度**。连接箭头的视觉缩进及双向偏移不改变时长，页面缩放也不改变时长。重叠位置不能播放。
4. 每个播放结点拥有 `nextArrow`，出边数组保持创建顺序。离开时选择该下标的出边，然后执行 `(nextArrow + 1) % outgoing.length`。每次开始播放都将所有结点计数归零；计数属于运行态，不保存到作品 JSON。
5. 到达终点的图单独淡出并保留终点游标；其他图继续。全部图结束才恢复编辑。环路持续播放，用户可按空格停止。
6. 每个数组位置维护一个持续振荡器，波形固定；边上几何进度 x 先通过该边的映射得到 y，再以 y 对频率（Hz）与增益进行线性插值。等分参数先求值为 Hz，不对等分参数或音分进行插值。映射不改变游标速度、边的时长和遍历顺序。
7. 音频调度使用 AudioContext 时间，提前 150ms 规划，每 25ms 补充。画面读取相同时间计算游标；经过结点不重启振荡器。遍历不会把已结束的无限历史保留在内存里。
8. 所有声音经过固定的会话混音缩放 `min(1, 0.8 / (voiceCount × 0.2))`；某个图结束不会改变其余图的音量比例。起止时使用短包络。
9. 播放/启动期间锁定图与声音编辑。空格表示开始/停止；再次开始从各图起点重播。进入后台、页面关闭或组件卸载时停止。启动异步等待期间的停止会使旧启动请求失效。

### 连接插值映射

- `linear`：y = x，默认值，保持原有线性音频调度。
- `floor`：x < 1 时 y = 0，x = 1 时 y = 1。音频以 `setValueAtTime` 精确切换，不额外平滑阶跃。
- `smoothstep`：令 t = clamp((x − 0.95) / 0.05, 0, 1)，y = t²(3 − 2t)。前 95% 保持起点值，最后 5% 完成过渡。音频使用此区间内的 128 个线性小段，归一化插值参数近似误差小于 0.000046；延迟调度会从当前 x 对应的曲线位置继续。

同一连接的全部声音共用该映射，频率与响度使用同一个 y。每条连接可以独立设置，播放期间下拉框锁定。映射持久化为连接上的 `mapping` 字段；旧版 v1 JSON 未提供该字段时按 `linear` 处理，非法映射在导入或播放校验时报错。

连接短到一次调度需要超过 10000 次跳转时会停止并提示拉开结点或降低速度，避免主线程被极端循环占满。浏览器主线程严重阻塞时，超过提前调度窗口的连接可能暂时保持端点声音；恢复后按音频时钟追上游标。此原型未引入 AudioWorklet。

## 保存与示例

画布使用 `harmonifold.canvas.v1` 保存到 localStorage，编辑自动保存。JSON 导出包含全部结点、声音参数、连接创建顺序、起点与速度；导入先进行结构验证。

旧单声音 URL 可迁移为一个草稿结点。第一次修改并成功保存后移除旧参数，避免刷新时反复覆盖画布。自动恢复失败时提示错误，直到用户编辑前保留原存储内容。

`docs/examples/independent-loops.json` 是两个独立循环：A→B→C→A（单正弦声音，约 8.33 秒）和 D→E→D（正弦与三角波两个声音，约 7.44 秒），全局速度 100。通过页面“导入”即可使用。
